Corvid v0.3.3 refines the macOS Desktop and Agent Deck experience and makes pending agent work easier to spot.

- macOS Desktop places workspace tabs beside the window controls, leaving more room for the terminal. [#164](https://github.com/DosangGu/corvid/pull/164)
- On macOS, Agent Deck uses the Corvid menu bar icon and opens directly below it. The panel follows the system appearance and shows connection and action messages under **Notifications → Deck status**. [#163](https://github.com/DosangGu/corvid/pull/163) · [#165](https://github.com/DosangGu/corvid/pull/165) · [#169](https://github.com/DosangGu/corvid/pull/169) · [#170](https://github.com/DosangGu/corvid/pull/170)
- Agent Deck prioritizes pending input requests, unread responses, and failures in a full grid. Pinned cards keep their priority protection. [#158](https://github.com/DosangGu/corvid/pull/158)
- Desktop shows the last update check in the system time zone. [#159](https://github.com/DosangGu/corvid/pull/159)

To update, open **Settings → About & updates** in Desktop or run `corvid update` for a script installation.
