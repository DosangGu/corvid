Corvid v0.5.3 adds live terminal previews when browsing tabs in Desktop and the TUI.

- In tab mode (`Ctrl+]`, then `t`), use the arrow keys or `h`/`l` to preview the highlighted tab's terminal contents. Press Enter to focus that tab and enable input, or Esc to return to the original tab. Tab previews over SSH require a daemon that supports `tab_preview.v1`.
