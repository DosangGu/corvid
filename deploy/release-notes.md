Corvid v0.4.1 fixes missing technical symbols and uneven terminal text alignment in Desktop.

- Desktop uses a bundled symbol font when the selected font lacks technical symbols such as `⎿` and `⏵`.
- Terminal text and IME composition share a row baseline when a glyph uses a fallback font.
