Corvid v0.6.0 moves terminal emulation into the standalone `corvidd` daemon and uses libghostty-vt for new terminal sessions. Desktop and TUI connect to the same daemon, and live terminal hosts keep their PTYs and shell state when the daemon is upgraded.

- GitHub Release packages include the matching `corvidd` for Linux and Windows x64 and ARM64, and for macOS Apple Silicon. Desktop also bundles the daemon payloads used for SSH and WSL provisioning. The Cargo-built TUI can download and verify the matching daemon if it is missing. [Daemon packaging](https://github.com/DosangGu/corvid/pull/380) · [On-demand installation](https://github.com/DosangGu/corvid/pull/383) · [WSL 2 lifecycle](https://github.com/DosangGu/corvid/pull/390)
- Desktop decodes ANSI frames without a native terminal engine. The daemon tracks each client's acknowledged frame, updates only changed screen rows, and compresses idle scrollback on Linux. [Desktop ANSI decoder](https://github.com/DosangGu/corvid/pull/397) · [Final libghostty migration](https://github.com/DosangGu/corvid/pull/398) · [Idle scrollback](https://github.com/DosangGu/corvid/pull/391)
- Agent Deck detects agent activity more reliably, restores observation after a daemon handoff, and removes cards when the corresponding agent process exits. [Activity detection](https://github.com/DosangGu/corvid/pull/365) · [Observer handoff](https://github.com/DosangGu/corvid/pull/376) · [Card cleanup](https://github.com/DosangGu/corvid/pull/396)
