Corvid v0.4.2 fixes Unicode font selection in Desktop and Agent Deck and a shutdown crash in Desktop on Linux.

- Desktop and Agent Deck honor Unicode text and emoji presentation selectors and use system fonts that cover the actual characters. [#292](https://github.com/DosangGu/corvid/pull/292)
- Color emoji in Desktop tab titles are vertically centered while surrounding text stays on its baseline. [#292](https://github.com/DosangGu/corvid/pull/292)
- Desktop on Linux can quit cleanly while a terminal pane has focus.
